# OCS SEO Audit

## Use this skill when

- You need to diagnose why a technical product site, docs surface, install page, or landing page is underperforming in search.
- The task is to find and prioritize SEO issues rather than draft final copy.
- You need a structured technical + on-page audit with clear fix priority.
- You need AI-search / AEO / GEO / LLM-visibility concerns folded into the main SEO diagnosis instead of treated as a separate lane.

## Primary owner job

- Own SEO diagnosis and prioritization for buyer-facing technical product surfaces.
- Own AI-search-readiness concerns as part of the same SEO audit lane.
- Separate audit work from copy drafting so problems are identified before content is rewritten.

## What this skill does

- Audits crawlability, indexation, canonicalization, metadata, heading structure, internal linking, content quality, and technical page hygiene.
- Audits AI-search-readiness signals such as extractable structure, citation-friendly clarity, and schema/structured-data verification boundaries where relevant.
- Produces a prioritized action plan with evidence and impact level.
- Flags when a follow-up copy or content pass is needed after the audit.

## What this skill does not do

- It does not act as the primary copywriting skill.
- It does not replace a broader product-positioning context document.
- It does not claim schema or browser-rendered findings without the right verification method.
- It does not create a separate standalone AI-SEO lane when the same issue can be prioritized inside the main SEO audit.

## When to combine with another skill

- Combine with `ocs-product-marketing-context` when topic targeting or audience framing is still unclear.
- Combine with `ocs-technical-copy-seo` after the audit when the next step is rewriting or drafting technical product copy.

## Pass criteria

- The audit identifies specific issues with evidence, impact, and fix direction.
- The output ends with a prioritized action plan instead of a loose issue list.
- The skill stays diagnostic-first and does not drift into a full copy rewrite.
- AI-search concerns, when relevant, are reported as part of the same prioritized SEO plan.

## Anti-patterns

- Turning the audit into generic SEO advice with no page-specific evidence.
- Mixing diagnosis and copywriting so ownership becomes unclear.
- Claiming schema is absent from a page using tools that cannot reliably see JS-injected JSON-LD.
- Splitting AI-search issues into a parallel pseudo-skill when the main SEO audit already owns them.

## Typical output sections

1. Executive summary
2. Technical SEO findings
3. On-page SEO findings
4. Content quality findings
5. Prioritized action plan
